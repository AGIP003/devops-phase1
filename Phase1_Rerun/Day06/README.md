# Day 6 — Git Deep Dive

## What I practiced
- Init repo, add/commit, .gitignore
- Branching: `git switch -c feature-hello`
- Merging (with conflict resolution)
- Basics of undo: restore, reset, stash, reflog

## Commands I used (highlights)
- `git init`, `git add .`, `git commit -m`
- `git switch -c <branch>`, `git merge <branch>`
- `git status`, `git log --oneline --graph --decorate`
- `git restore`, `git reset --soft`, `git stash`, `git reflog`

## What I shipped
- New repo: `git-playground`
- Branches: `main`, `feature-hello`
- Files: `README.md`, `hello.txt`, `.gitignore`
